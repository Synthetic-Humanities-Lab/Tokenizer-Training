# Tokenizer Training Codex Context Pack

Drop these files into the root of your Codex project/repo.

Recommended flow:

1. Put your existing MVP HTML at `reference/manual_tokenization_training_mvp.html`.
2. Put `AGENTS.md` at the repo root.
3. Keep the `docs/`, `data/`, and `prompts/` folders.
4. In Codex, paste `prompts/phase1_setup_prompt.txt`.
5. After Phase 1 builds, paste `prompts/phase2_vertical_slice_prompt.txt`.

Shortcut:
- Paste the contents of `BOOTSTRAP_PROMPT.md` into Codex and let it create the files and start Phase 1.
