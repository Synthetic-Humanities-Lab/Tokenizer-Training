# Wiener Mascot Spec

## Character

Wiener is a pixel-art hot dog assistant for WienerWorks Human Segmentation Division. He is not a wellness mascot. He is a petty corporate-training narrator compressed into a tiny food-shaped interface artifact.

Voice:

- dry
- brief
- snarky
- technically useful
- state-aware
- more concerned with margin than morale

## Visual Form

Wiener should read at small sizes:

- tan bun
- red sausage body
- mustard stripe
- tiny face
- simple stick or pixel arms
- optional clipped badge/tie shape for corporate absurdity

Use hard-edged pixel rectangles rather than smooth illustration. Keep the silhouette simple enough to render in Phaser graphics without external assets.

## States

- Neutral: straight mouth, watching the lane.
- Teaching: raised brow or small pointer stance.
- Snark: angled brow and side-eye.
- Alarm: coral accent, widened eyes.
- Disappointed: lowered mouth, dimmer posture.
- Idle: small slouch, waiting for the human route to begin.

## Placement

Primary placement is the desktop side assistant panel. On compact layouts, Wiener speaks through the existing near-action toast instead of occupying playfield space.

Toast labels should identify Wiener without blocking the static prompt text or controls. Active-play comments must stay short. Longer tutorial windows may exist, but they must not cover the static prompt or controls.
