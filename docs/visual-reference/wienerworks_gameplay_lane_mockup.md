# WienerWorks Gameplay Lane Mockup

## Segmentation Lane

The playfield should feel like a segmentation lane: the prompt travels through a clean interface route, and the player cuts it at predicted token boundaries. The lane is a motion grammar, not a prop.

Elements:

- faint left and right lane rails
- small timing ticks along the text path
- a soft horizontal cut band at the active slice zone
- subtle lane centering cues around the static prompt
- low-contrast background sweep lines that never compete with the text
- cut preview and staged cuts that sit clearly on top of the prompt

The text remains the object moving through the interface. The UI does not need a belt, rollers, crates, packages, pistons, gears, or machinery.

## Conveyor-Belt Feeling Without Factory Props

The conveyor-belt feeling comes from:

- regular timing marks
- a stable route
- an active cut band
- static centered prompt with a brief acquisition beat
- review evidence that files what passed through the lane

It must not come from literal industrial imagery. Avoid rollers, belt texture, crates, package silhouettes, mechanical arms, warning stripes, factory floor grating, or anything that makes the lane the central object. The prompt is the central object.

## Readability

The prompt has priority over every lane cue. Rails, ticks, and band fills should stay faint enough that token characters remain crisp at desktop, portrait phone, and small-phone viewports. The cut band should help the player know where action matters without hiding the static prompt text.
