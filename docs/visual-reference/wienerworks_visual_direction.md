# WienerWorks Visual Direction

## Aesthetic Principles

WienerWorks should read as clean contemporary AI software with a degraded labor purpose. The surface is warm, calm, polished, and interface-native. The hostility comes from process language, cost accounting, disabled help, audit labels, and the fact that a human is doing human segmentation under time pressure.

Use warm off-white panels, mint and teal interface cues, quiet amber action states, muted coral warnings, crisp dark text, and soft shadows. The interface should feel too polite for what it is asking the player to do.

Wiener is a small pixel-art hot dog assistant. He is funny, snarky, technically useful, petty, and a little pathetic. He should not become crude, lewd, cuddly, heroic, or branded like an existing assistant.

## Change From Old Direction

The old direction emphasized a dated AI browser, haggard enterprise chrome, degraded glass, and obsolete computing. The new direction keeps the labor critique but changes the visual surface to polished 2026-style AI product software.

Do not carry forward cyberpunk, hacker terminal, literal old operating-system beige, or broken-dashboard cues. The game can still be bureaucratic and hostile, but it should look maintained.

## Mechanical Constraints

Do not change the core game:

- text appears and scrolls through the active playfield
- the player swipes or cuts predicted token boundaries
- real tokenizer fixtures resolve the round
- correct, missed, and false cuts are scored
- pay, company cost, net, balance, rank, and review feedback remain intact
- endless progression and tutorial flow remain intact
- Vite, TypeScript, and Phaser architecture remain intact

## Copy Separation Rule

Design descriptions belong here, not in the game UI.

In-game copy must stay diegetic. Good UI copy names operational conditions:

- Biological fallback active.
- Human segmentation route assigned.
- Help disabled to preserve margin.
- Audit window open.
- The model has declined to think about this.
- Accuracy before interpretation.

Do not write UI copy that explains the game as a dated browser, a future artifact, or a design concept.
