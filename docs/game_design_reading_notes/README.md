# Game Design Reading Notes

These notes synthesize the source PDFs in `../Game Design Reading and Principles/`.
They are written as design working notes, not substitutes for the books. Each book
has one synoptic note and chapter-level notes that extract consequences for
Tokenizer Training.

`chapter_note_manifest.md` is the inventory of note units. It treats each linked
section as a separate chapter/source-section note while preserving one readable
file per book.

## Sources

- Mary Flanagan, `Critical Play`
- Katherine Isbister, `How Games Move Us`
- Steve Swink, `Game Feel`
- Edward Tufte, `The Visual Display of Quantitative Information`
- Robert Zubek, `Elements of Game Design`

## How To Use These Notes

Use the book notes to keep design decisions accountable to specific traditions:

- Zubek: loop structure, systems, playtesting, and player experience.
- Swink: swipe responsiveness, snap feedback, timing, and tactile clarity.
- Tufte: HUD discipline, readable metrics, and visual evidence.
- Flanagan: the game as conceptual critique, not only training content.
- Isbister: emotional stakes through agency, bodily input, and connection.

The companion repository in `docs/game_design_concepts/` converts these readings
into implementation guidance and playtest gates.
