# Chapter Note Manifest

This manifest makes the note granularity explicit. The repository keeps each
book in one source file for readability, but each linked `##` section below is a
separate note unit: one synoptic note for the book and one note for each
chapter, introduction, conclusion, epilogue, or other source division covered by
the reading file.
