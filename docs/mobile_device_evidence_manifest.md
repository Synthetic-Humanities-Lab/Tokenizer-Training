# Tokenizer Training Mobile Device Evidence Manifest

Store physical-device evidence in `docs/mobile_device_evidence/`. This directory is ignored by Git because it can contain local photos, screen recordings, and private device captures.

Use these filenames unless there is a concrete reason to rename an artifact. If you rename one, update `docs/mobile_device_validation_completed.md` to match the exact saved filename.

Some stable filenames retain earlier internal terms such as `endless` or `best-record`. Keep those filenames for evidence continuity, but use the current UI language in checklist and inventory labels.

| Evidence item | Preferred artifact | Required content |
| --- | --- | --- |
| Small-phone menu | `small-phone-menu.jpg` | iPhone SE or similarly small phone in portrait, showing WienerWorks, Wiener, `Tokenizer Training`, visible `Best Rank`, and the `Tutorial`, `Training`, `Token Log`, and `Settings` actions without clipping. There is no menu Sound control. |
| Small-phone active tutorial after at least one staged cut | `small-tutorial-cut.mov` | Real finger/touch input staging at least one cut, with prompt and cut marker visible. |
| Small-phone review feedback card | `small-review-feedback.jpg` | Feedback card showing segmentation, token split, verified/rework/net credits, and boundary audit without a separate token strip. |
| Standard-phone Training observation sample | `standard-endless-five-rounds.mov` | One uncapped Training run on a standard portrait phone showing at least five consecutive resolved rounds, readable review/advance flow, and the transition from round five into another round while Token Credits remain. Five rounds is an observation sample, not a completion boundary. |
| Large-phone menu | `large-menu.png` | Large portrait phone menu showing visible `Best Rank` and the `Tutorial`, `Training`, `Token Log`, and `Settings` actions, with safe areas clear, no menu Sound control, and no desktop-only layout leakage. |
| Large-phone active play | `large-active.png` | Large portrait phone active play with HUD, prompt/playfield, Wiener speech, and bottom controls visible. |
| Native relaunch persisted Best Rank | `native-relaunch-best-record.jpg` | Default menu after a real Training result, full native-app termination, and normal relaunch without a QA route override, showing the same visible `Best Rank` and rounds. |
| Native relaunch persisted Sound Off in Settings | `native-relaunch-sound-off.jpg` | Settings after a full native-app termination and normal relaunch, visibly showing `Sound: Off`. The associated observer note or recording must confirm that `Sound: Off` was set in Settings before termination. A menu capture or QA metadata is not proof. |
| Observer note on thumb reach, finger occlusion, touch latency, and audio output | `observer-note.md` | Notes on one-handed reach for play-screen `Sound`/`Muted`, `Clear`, `Exit`, `Resolve`, `Next`, `Continue`, and `Finish`; Results `Review Token Log`, `Run Training Again`, and `Return to Menu`; finger/hand occlusion; perceived touch latency or trust; no boot audio; user-action audio; and setting `Sound: Off` in Settings before termination. `npm run mobile:prepare` creates this from `docs/mobile_device_observer_note_template.md` if absent. Text-only notes are acceptable if copied directly into the completed validation file, but missing play-screen reach, Results reach, occlusion, latency/trust, audio/boot, or pre-termination Sound Off observations fail the packet. |
| Input-feel copied summary or trace | `input-feel-summary.md` | Copied summary or observer trace with first-cut latency, no-cut acknowledgement behavior, touch-loupe clearance or finger visibility, cut batch or broad-swipe ownership, and resolve timing or hesitation. `npm run mobile:prepare` creates this from `docs/mobile_device_input_feel_summary_template.md` if absent. |
| Desktop browser pinned fixture | `desktop-pinned-fixture.png` | Desktop browser harness for `?mode=endless&playtestReset=1&qaViewport=1280x720&qaFreezeElapsedMs=6200&qaFixtureId=simple_001`, showing the browser layout remains intact and does not inherit mobile bottom-docked controls. `npm run mobile:desktop-evidence` can seed this local artifact and its validation rows after `npm run mobile:local` has refreshed the source evidence. |

`npm run mobile:validate` checks that every referenced `.png`, `.jpg`, `.mov`, `.mp4`, or `.md` artifact exists under `docs/mobile_device_evidence/` unless a different `--evidence-root` is supplied. Image artifacts must contain real PNG/JPEG bytes, video artifacts must look like MP4/QuickTime recordings rather than placeholder text files, observer-note markdown must contain substantive play-screen reach, Results reach, finger occlusion, latency/trust, audio/boot, and pre-termination `Sound: Off` observations, and input-feel markdown must contain the metric families listed above. The packet remains incomplete unless the Best Rank image shows the default menu after full relaunch and the Sound Off image shows Settings after full relaunch.
